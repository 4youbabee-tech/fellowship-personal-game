# Rights Holders, Weta Workshop and Resource Outreach

## Practical conclusion

Weta Workshop is extremely valuable to this project, but in a different role from Fab, Poly Haven or Sketchfab. It is a professional design/manufacturing/game-development studio and can accept game concept design, game-development and private-commission enquiries. It is **not** treated as a stock-asset library and it cannot automatically license every Middle-earth design it helped create.

Weta's own FAQ says requests to use project images should be sent to its press team and notes that it sometimes cannot share material because the intellectual property is not Weta's. Therefore Weta is a potential professional partner/reference/commission source, not a shortcut around the Tolkien/film rights chain.

## Rights map for this project

- **Middle-earth Enterprises / Embracer:** first official licensing contact for The Lord of the Rings / The Hobbit game-related rights. Their public licensing process is business-oriented and does not promise a private fan-game exception.
- **Warner Bros. Discovery / New Line:** film-specific material from the Peter Jackson films is a separate layer. Treat film stills, clips, actor likenesses, exact film props/costumes and film audio as requiring film-rights clearance.
- **Tolkien Estate:** controls important Tolkien copyright/trademark interests and explicitly protects Tolkien's original artwork, maps, writings and other material. Private/non-profit status is not treated by this project as blanket permission.
- **HarperCollins Permissions:** published text/quotation permissions.
- **Weta Workshop:** concept design, game development, private commissions and craft/design expertise; underlying franchise rights still remain with the applicable rights holders.

## Best-use-by-source rule

Use each source for what it is best at:
- Weta Workshop -> design language, professional concept/game-development/commission enquiries.
- Fab / Megascans -> UE-compatible environment kits, scans, materials.
- Poly Haven / ambientCG -> CC0 HDRIs, textures, materials and 3D environment resources.
- Mixamo / ActorCore -> rigging and animation acceleration, subject to their terms.
- Sketchfab / TurboSquid / CGTrader -> selective models only after item-level license review.
- Sonniss / Freesound / commercial audio libraries -> SFX and ambience under tracked audio licenses.
- Tolkien Gateway / LOTR Wiki -> research, chronology and source discovery, not asset extraction.
- ArtStation -> visual research/inspiration, not automatic asset reuse.

## Private-project rule

The project being personal, local and non-distributed is useful context for a permission request, but it does not automatically convert protected film/book material into freely usable production content. Our safest production default remains:
1. project-owned original art,
2. generic third-party assets with clear licenses,
3. protected franchise material only when written permission/license evidence exists.

## Outreach status

Research is complete for the major official rights/production channels above. No rights-holder email has been sent from ChatGPT yet. If outreach is made, it should be narrow, polite, explicitly non-commercial/private, and ask what permission route actually exists rather than claiming one.
