# External Licensed Asset Staging

- `Inbox/` is local-only and ignored by Git. Put candidate downloads there first.
- `Approved/` is for assets that have a matching approved record in `Data/ExternalAssetManifest.json`.
- Do not move a file into Approved until provider, asset ID, license class, acquisition date, source URL and required attribution/proof are recorded.
- Editorial-only, non-commercial, no-derivatives, unknown-license and ripped franchise assets are not allowed.
