# Private Offline Asset Lane

This directory is reserved for owner-supplied or externally sourced media used only by the private offline Shire Journey experience.

- Payload files are intentionally ignored by Git.
- Keep source/provider/original filename and known license status in the private-offline intake registry.
- These assets are not part of the distributable/commercial Framework.
- Do not hard-reference private payloads from reusable Framework code.
- Provider access restrictions still apply: no authentication/paywall/DRM/anti-bot bypass.
- Animated production candidates must still end in FBX for the UE4.27 pipeline; production texture intake remains PNG/TGA.
