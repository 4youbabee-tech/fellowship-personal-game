## Project identity

Shire Journey is a personal Unreal Engine **4.27.2** C++ project using the Peter Jackson *The Lord of the Rings* film continuity as the mandatory main-story spine, enriched by source-grounded exploration, living-world systems and compatible detail from Tolkien's *The Lord of the Rings* + Appendices.

## Permanent story/source rule

The Timeline Bible organizes the trilogy journey; it does **not** define a maximum amount of story or world detail.

On `develop`, the Project Governor and Source Reference Index define the permanent source chain:

`Timeline -> film/screenplay -> Tolkien narrative/Appendices -> Sources 02-11 -> implementation/disposition`.

Compatible Tolkien material omitted or compressed by the films may become real playable content when it preserves the required film outcome, chronology and character-knowledge boundaries. Meaningful discovered source detail is not silently discarded.

## Localization product rule

Spoken VO remains English. Arabic covers subtitles, objectives/quest directions, menus, settings, HUD/system guidance and tutorial text. Canonical Middle-earth location labels on the map remain in their original English names.
